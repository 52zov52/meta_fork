# Scribe API Docs

## Overview

PHPDoc style for Scribe (Scalar theme) in this Laravel project. All docs are in Russian. Scribe does NOT auto-extract validation rules (`GetFromInlineValidator` removed in config). Every parameter and response must be written explicitly.

## When to Document

- Any new or modified controller method exposed via API.
- Any change to request parameters, response shape, or auth requirements.

## Rules

- **Language:** Russian for all text, descriptions, and examples.
- **Auth:** Default is Bearer token (`Authorization` header). Mark public endpoints with `@unauthenticated` only. Never use `@authenticated`.
- **Headers:** `Content-Type` and `Accept` are global in config. Never use `@headerParam`.
- **GET responses:** `@response 200` is auto-generated by `ResponseCalls`. Do NOT write it manually UNLESS the auto-generated output is broken (complex `DB::raw`, `whereHas`, etc.). In that case add `@response 200` and note `(ResponseCalls broken)` in description.
- **POST/PUT/PATCH/DELETE responses:** `@response` MUST be written manually (success + every handled error code).
- **Array type:** Always use `<type>[]` (`integer[]`, `string[]`). `array` without element type is forbidden.
- **Example keyword:** Always `Example:`. `Пример:` is forbidden.
- **File params:** Never add `Example:` for `file` type. Scribe generates a fake file.
- **Enums / filters:** List allowed values in description text, not in type (`string` + text `draft, scheduled, started`).

## Tag Order (strict)

```
/**
 * <Summary: verb-first Russian phrase>
 *
 * <Description: business context, restrictions>
 *
 * @group <Domain> (<Role>)
 * @unauthenticated
 *
 * @urlParam  name type required|optional Description. Example: value
 * @queryParam name type required|optional Description. Example: value
 * @bodyParam  name type required|nullable Description. Example: value
 *
 * @response <code> [scenario="..."] <{JSON} or binary>
 */
```

Order:
1. Summary (first line)
2. Description (blank line after)
3. `@group` (blank line after)
4. `@unauthenticated` (same line as next if absent; skip blank line before)
5. `@urlParam` block (no blank lines between params; blank line after block)
6. `@queryParam` block (same spacing)
7. `@bodyParam` block (same spacing)
8. `@response` block (ordered: success first, then errors)

## `@group`

- Class level: domain only (`Activities`, `Users`, `Portfolio`, `Notifications`, `Reporting`, `Settings`, `Marketplace`, `Rating`...).
- Method level: domain + role in parentheses (`Activities (Mentor)`, `Users (Admin)`, `Portfolio (Student)`).
- Public endpoints without role: `Public Endpoints`.

## `@urlParam`

- Type: `integer` or `int` (both allowed), `string`.
- URI path params are implicitly required — mark `required` explicitly.
- End description with period before `Example:`.

## `@queryParam`

- Type MUST be explicit.
- For pagination: include range in description (`1–100`).

## `@bodyParam`

- Valid types: `string`, `integer`/`int`, `boolean`, `file`, `number`, `<type>[]`.
- Validation rules go into description text (e.g. `Пароль (минимум 8 символов)`).
- Arrays:
  ```
  @bodyParam user_ids   integer[] required IDs. Example: [1, 2, 3]
  @bodyParam user_ids.* integer   required ID. Example: 1
  ```

## `@response`

- Inline JSON only. `@responseFile` and `@responseField` are forbidden.
- Every handled error code (400, 403, 404, 422, 500) MUST have a `@response` if the code branches to it.
- Binary downloads: `@response 200 binary`.

## Examples

**GET with query (auto response):**
```php
/**
 * Получить мероприятия ментора
 *
 * @group Activities (Mentor)
 *
 * @urlParam user_id integer required ID ментора. Example: 5
 *
 * @queryParam status   string  Фильтр по статусу: draft, scheduled, started, completed, canceled. Example: scheduled
 * @queryParam per_page integer Количество элементов на странице (1–100). Example: 20
 */
```

**POST with body + errors:**
```php
/**
 * Создать уведомление
 *
 * @group Notifications (Admin)
 *
 * @bodyParam user_id     int     required ID пользователя. Example: 15
 * @bodyParam title       string  required Заголовок. Example: "Новое сообщение"
 * @bodyParam description string  required Текст. Example: "Вам пришло новое сообщение."
 * @bodyParam checked     boolean          Прочитано. Example: false
 *
 * @response 201 scenario="Created" {"message":"Уведомление успешно создано!"}
 * @response 422 scenario="Validation error" {"message":"The given data was invalid."}
 */
```

**GET with manual response (auto broken):**
```php
/**
 * Получить дашборд
 *
 * Агрегированные данные с подзапросами. (ResponseCalls broken)
 *
 * @group Users (Student)
 *
 * @urlParam user_id int required ID пользователя. Example: 2
 *
 * @response 200 {"total_score": 1250, "activities_count": 15}
 */
```

## Checklist

- [ ] Summary starts with a verb in Russian.
- [ ] `@group` present on class and method (with role).
- [ ] `@unauthenticated` added if public; omitted otherwise.
- [ ] All `@urlParam`, `@queryParam`, `@bodyParam` have type + required/optional + `Example:`.
- [ ] No `array` type — only `<type>[]`.
- [ ] No `Example:` on `file` params.
- [ ] GET has no `@response 200` unless auto-generation is broken.
- [ ] POST/PUT/PATCH/DELETE has success `@response`.
- [ ] Every error branch (400, 403, 404, 422, 500) has `@response`.
- [ ] `php artisan scribe:generate` runs without red warnings.
